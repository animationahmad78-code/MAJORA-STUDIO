# وضعیت پیاده‌سازی — ۲۰ اکتبر ۲۰۲۶

این گزارش فقط قابلیت‌های موجود در فایل‌های پروژه را ثبت می‌کند. «آزموده» در این صفحه به معنی آزمون واحد/یکپارچه‌سازی روی Windows است، نه آزمون روی گوشی.

| بخش | وضعیت واقعی |
|---|---|
| فضای دائمی و منابع | `D:\desktop\MAJORA-STUDIO`، هفت تصویر اصلی و چهار فونت Estedad بدون ویرایش، ثبت SHA-256 |
| اسناد محصول | brief، PRD فارسی، معماری، سناریوها، پرسش‌ها و ماتریس نیازها |
| مونوریپو | npm workspaces، React/TypeScript، Capacitor 8 و پروژهٔ native Android ساخته و sync شده؛ آیکن/آغازین از کپی بدون تغییر نشان فروشگاه استفاده می‌کنند، رندر دستگاه باز است |
| دادهٔ آفلاین | در Android از SQLite بومی؛ در مرورگر فقط localStorage نمایشی |
| کالا و انبار | ثبت کالا با موجودی اولیه و دفترکل، جست‌وجوی ساده، ویرایش قیمت؛ عکس/حذف/ویرایش همهٔ مشخصات کامل نیست |
| قیمت گروهی | اعمال درصد و بازگردانی آگاه از تعارض در تراکنش SQLite؛ تست شده |
| فاکتور | صدور یک ردیف کالا از UI Android؛ موتور پایگاه داده چند ردیف و ردیف دستی را می‌پذیرد؛ شمارهٔ یکتا، snapshot، کسر موجودی و retry ایمن تست شده |
| قالب | متن هویت/شش شرط در Android به‌صورت نسخه‌دار ذخیره و هنگام صدور snapshot می‌شود؛ جابه‌جایی، مرزبندی و کنترل تک‌تک اجزای بصری هنوز پیاده نیست |
| خروجی فاکتور | پیش‌نمایش A4 رنگی/تک‌رنگ و چاپ مرورگر؛ چاپ/PDF/PNG بومی Android فعلاً غیرفعال |
| پشتیبانی MAJORA | صفحهٔ تماس با دو شماره و اینستاگرام؛ تلگرام بنا به درخواست کاربر نمایش ندارد |
| CSV/XLSX، SMS، پشتیبان رمزدار، چند دستگاه | در PRD و معماری تعریف شده؛ هنوز پیاده نیست |
| APK/AAB | پروژهٔ Android وجود دارد؛ فایل نصب‌شدنی ساخته و روی دستگاه آزموده نشده است |

آزمون: `npm test` = ۱۰ آزمون موفق؛ `npm run build` و `npx cap sync android` موفق؛ `npm audit` بعد از پین نسخهٔ CLI = صفر هشدار. Android SDK/JDK/دستگاه در این محیط پیدا نشد. اعتبارسنجی واقعی چاپ، فونت روی دستگاه، RTL و بازگردانی پشتیبان باقی است.
