# رویدادهای ورود و خروج — ۱۱ نوامبر ۲۰۲۶

- ورود موفق، رمز نادرست، حساب غیرفعال، اشتراک غیرفعال، پرشدن سقف نشست و خروج در تاریخچه ثبت می‌شوند. متن پاسخ ورود نامعتبر همچنان عمومی است و وجود حساب را افشا نمی‌کند.
- رخدادها شناسهٔ کاربر شناخته‌شده، زمان، شناسهٔ نشست در صورت وجود، دلیل کدگذاری‌شده و IP را ثبت می‌کنند؛ **رمز عبور و نام کاربری تلاش ناشناس ذخیره نمی‌شوند**. تلاش ناشناس در تاریخچهٔ سراسری MAJORA با نام «ناشناس» دیده می‌شود.
- مالک فروشگاه، رویدادهای شناخته‌شدهٔ فروشگاه خود را در صفحهٔ فعالیت‌ها می‌بیند. مالک MAJORA می‌تواند رویدادهای سراسری را ببیند. توضیح علت‌ها در رابط به فارسی نمایش داده می‌شود.
- آزمون API با پایگاه موقت، تلاش ناشناس، رمز اشتباه کاربر شناخته‌شده، ورود موفق، خروج و رد شدن به‌علت سقف نشست را بررسی کرد و گذشت.
- سیاست زمانی نگهداری و حذف کنترل‌شدهٔ رویدادهای امنیتی، آزمون SQL Server و آزمون مرورگر هنوز باز هستند. رخدادهای مالی و ممیزی حساس نباید با پاک‌سازی خودکار رویدادهای امنیتی حذف شوند.
