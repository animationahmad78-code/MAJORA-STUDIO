# پیشرفت تولید از ۲۱ اکتبر ۲۰۲۶

## فاز A — انجام شد

گزارش کامل در `PROJECT_AUDIT.md` است. پشتیبان پیش از ویرایش در `07-BACKUPS/pre-production-source-2026-10-21.zip` نگهداری می‌شود. آزمون پایه ۱۰/۱۰، build وب، sync Android و اعتبارسنجی ۱۷ جدول موفق بود.

## فاز B — در جریان

- ویرایش نام، دسته، قیمت و موجودی و بایگانی نرم کالا به مخزن SQLite و UI افزوده شد. تغییر قیمت و موجودی در همان تراکنش به دفترکل و audit نوشته می‌شود و فاکتور قدیمی پس از بایگانی حفظ می‌شود.
- دو آزمون تازه برای ویرایش/دفترکل/بایگانی و رد ویرایش نامعتبر افزوده شد. نتیجه: ۱۲/۱۲ آزمون موفق؛ build وب و sync Android موفق.
- رابط فاکتور چندردیفی و ردیف دستی به همان موتور صدور تراکنشی وصل شد. پیش‌نمایش مرورگر با یک کالا و یک ردیف دستی بررسی شد: جمع ۱۲۳٬۴۵۶ + ۱٬۰۰۰ = ۱۲۴٬۴۵۶ ریال. این آزمون، صدور native یا چاپ را اثبات نمی‌کند.
- اسکیل UI UX Pro Max Complete برای برچسب فرم‌ها، صفحه‌کلید عددی، وضعیت ثبت و اندازهٔ دکمه‌ها بررسی شد. نتیجهٔ عمومی آن دربارهٔ فونت لاتین/صفحهٔ بازاریابی بر طرح تأییدشدهٔ فارسی و Estedad مقدم نیست.
- APK، آزمون دستگاه، عکس کالا، پشتیبان/بازیابی، PDF/چاپ بومی، Excel/CSV، پیامک و جریان کامل فاکتور هنوز تأیید نشده‌اند.

## فاز C — آماده‌سازی ابزار

- Microsoft OpenJDK 17.0.20.1 از منبع رسمی دریافت و SHA-256 آن با رکورد رسمی برابر بود: `3D9006956FC8AF5601CD24FFC4F468BEF48279C7EBD8171B9BDF90D0AABFBF1F`.
- کاربر پذیرش قرارداد Android SDK را تأیید کرد. Google در لینک مستقیم `dl.google.com` پاسخ ۴۰۴ می‌دهد؛ لینک رسمی CDN به HEAD پاسخ ۲۰۰ داد، اما دانلود کامل در این محیط قبل از دریافت داده با reset/timeout قطع شد. هیچ SDK یا APK کامل ادعا نمی‌شود.
- همین خطای ۴۰۴ در Chrome روی لینک رسمی صفحهٔ Google نیز مشاهده شد. مسیر CDN در مرورگر این دستگاه مسدود و دانلود با ابزار خط فرمان قبل از دریافت داده قطع شد.
- اسکریپت اعتبارسنجی migration با Python بسته‌بندی‌شدهٔ محیط اجرا شد: ۱۷ جدول، بدون خطای کلید خارجی.

## فاز F — آماده‌سازی سورس iOS، بدون IPA

- `@capacitor/ios@8.5.3` به پروژهٔ موجود اضافه شد. `cap add ios` و `sync:ios` روی Windows موفق‌اند؛ افزونهٔ SQLite در SPM شناسایی شد.
- مسیر نسبی SPM تولیدشده روی Windows با اسکریپت `normalize-ios-spm.mjs` اصلاح می‌شود. ساخت Xcode روی macOS هنوز اجرا نشده است.
- workflow دستی برای آزمون کامپایل شبیه‌ساز روی `macos-26` و بستهٔ خصوصی دارایی‌ها آماده شد؛ Git remote، secrets، Apple Developer و امضا در دسترس نیستند. IPA وجود ندارد.
