## فاز B — در جریان

- ویرایش نام، دسته، قیمت و موجودی و بایگانی نرم کالا به مخزن SQLite و UI افزوده شد. تغییر قیمت و موجودی در همان تراکنش به دفترکل و audit نوشته می‌شود و فاکتور قدیمی پس از بایگانی حفظ می‌شود.
- آزمون‌های ویرایش/دفترکل/بایگانی، رد ویرایش نامعتبر و ابطال تراکنشی فاکتور افزوده شد. نتیجهٔ فعلی: ۱۳/۱۳ آزمون موفق؛ build وب، sync Android و iOS و اعتبارسنجی ۱۷ جدول موفق.
- رابط فاکتور چندردیفی و ردیف دستی به همان موتور صدور تراکنشی وصل شد. پیش‌نمایش مرورگر با یک کالا و یک ردیف دستی بررسی شد: جمع ۱۲۳٬۴۵۶ + ۱٬۰۰۰ = ۱۲۴٬۴۵۶ ریال. این آزمون، صدور native یا چاپ را اثبات نمی‌کند.
- فاکتور صادرشده اکنون با دلیل اجباری فقط یک‌بار باطل می‌شود؛ موجودی همان تراکنش بازمی‌گردد، متن اصلی سند محفوظ می‌ماند و شناسهٔ باطل‌شده برای صدور دوباره پذیرفته نمی‌شود. رابط، تاریخچهٔ صادرشده/باطل‌شده و جست‌وجوی شماره، خریدار، نام کالا و تاریخ را نشان می‌دهد. این مسیر هنوز روی دستگاه واقعی آزمایش نشده است.
- اسکیل UI UX Pro Max Complete برای برچسب فرم‌ها، صفحه‌کلید عددی، وضعیت ثبت و اندازهٔ دکمه‌ها بررسی شد. نتیجهٔ عمومی آن دربارهٔ فونت لاتین/صفحهٔ بازاریابی بر طرح تأییدشدهٔ فارسی و Estedad مقدم نیست.
- Debug APK ساخته و ساختار، شناسه و امضای آن بررسی شد. آزمون دستگاه، عکس کالا، پشتیبان/بازیابی، PDF/چاپ بومی، Excel/CSV، پیامک و جریان کامل فاکتور هنوز تأیید نشده‌اند.

## فاز C — آماده‌سازی ابزار

- Microsoft OpenJDK 17.0.20.1 از منبع رسمی دریافت و SHA-256 آن با رکورد رسمی برابر بود: `3D9006956FC8AF5601CD24FFC4F468BEF48279C7EBD8171B9BDF90D0AABFBF1F`.
- کاربر پذیرش قرارداد Android SDK را تأیید کرد. دانلود SDK در میزبان Windows به دلیل خطا/timeout کامل نشد؛ ساخت ابری مستقل از این محدودیت انجام شد.
- همین خطای ۴۰۴ در Chrome روی لینک رسمی صفحهٔ Google نیز مشاهده شد. مسیر CDN در مرورگر این دستگاه مسدود و دانلود با ابزار خط فرمان قبل از دریافت داده قطع شد.
- اسکریپت اعتبارسنجی migration با Python بسته‌بندی‌شدهٔ محیط اجرا شد: ۱۷ جدول، بدون خطای کلید خارجی.
- اسکریپت ساخت محلی با اعتبارسنجی مسیر واقعی SDK و workflow دستی Android روی GitHub Actions آماده است. ساخت ابری موفق شد؛ جزئیات در `android-build-readiness.md` است.
- مخزن کد GitHub در حساب مالک ایجاد و عمومی شد. مالک سپس خواست فایل‌های برند این مشتری برای به‌روزرسانی یکپارچه در همین مخزن باشند؛ workflowهای Android/iOS به همین مخزن بازگردانده شدند. بستهٔ خصوصی موقت دیگر برای build لازم نیست. دیتابیس، پشتیبان و کلید امضا همچنان خارج از Git هستند.
- اجرای Android شمارهٔ `39590835556` در Gradle با Java 17 شکست خورد. پس از اصلاح Java 21، اجرای `39599628878` موفق شد. APK آزمایشی استخراج و SHA-256 آن با لاگ CI برابر شد؛ امضای v2 و شناسهٔ بسته نیز در CI بررسی شدند. گزارش تحویل در `qa-debug-apk-2026-10-21.md` است.
