## آزمون‌های انجام‌شده

- `npm run build -w @majora/web`: قبول؛ خروجی React در `apps/web-api/wwwroot` تولید شد.
- `npm test` مونوریپو: ۳۰ آزمون در ۵ فایل قبول؛ `npm run build` اپ Android نیز قبول، با هشدار قدیمی اندازهٔ chunk.
- `dotnet build`: قبول، صفر هشدار و صفر خطا.
- `test-web-api.ps1` با PowerShell 7: قبول؛ ورود، اشتراک، دو فروشگاه، جداسازی داده، فاکتور/موجودی/پرداخت، پیش‌فاکتور، خرید/هزینه، نقش کارمند، CSRF و تعلیق.
- `test-web-package.ps1` روی فایل منتشرشدهٔ Windows: قبول؛ API و صفحهٔ React از خروجی publish پاسخ دادند.
- آرشیو Windows از نظر وجود `Majora.WebApi.dll`، `wwwroot/index.html` و assetهای CSS/JS بررسی شد.
