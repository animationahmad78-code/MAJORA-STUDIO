# نسخهٔ محلی ماندگار ویندوز — ۹ نوامبر ۲۰۲۶ UTC

این نصب برای دیدن و استفادهٔ محلی از نسخهٔ فعلی وب MAJORA روی **همین حساب ویندوز** است. نسخهٔ وب هنوز برابر کامل APK و آمادهٔ استقرار تجاری نیست.

## محل‌ها و روش بازکردن

- فایل برنامه: `%LOCALAPPDATA%\MAJORA\LocalWeb\app\`؛ از بستهٔ Windows مورخ `20261109-071427` استخراج شد. نسخه‌ای از همان بسته در `06-BUILDS-AND-RELEASES/MAJORA-LOCAL-WINDOWS/` نیز باقی است، اما میانبر به نصب داخل پروفایل ویندوز وصل است.
- میانبر روی دسکتاپ: «ماژورا - کیف و کمربند کلاسیک». اجرای آن، سرور محلی را در پس‌زمینه روشن می‌کند و نشانی `http://127.0.0.1:5188/` را باز می‌کند. اگر سرور از قبل روشن باشد، فقط همان صفحه باز می‌شود.
- دادهٔ ماندگار: `%LOCALAPPDATA%\MAJORA\LocalWeb\majora-local.db`. این مسیر از فایل‌های برنامه و پوشه‌های موقت جداست. راه‌انداز اگر دیتابیس را پیدا نکند، متوقف می‌شود تا برنامهٔ خالی را به‌اشتباه به جای دادهٔ قبلی نشان ندهد.
- کد منبع راه‌انداز در `01-CORE-PLATFORM/tooling/local-windows/` نسخه‌بندی شده است. نسخهٔ اجرایی همان دو فایل داخل پوشهٔ نصب قرار دارد. سرور فقط روی `127.0.0.1` گوش می‌دهد، نه شبکهٔ محلی.
- یک تصویر اولیهٔ دیتابیس با روش پشتیبان آنلاین SQLite در `07-BACKUPS/MAJORA-local-initial-20261109-072734.db` ساخته شد. این **پشتیبان اولیه** است و پشتیبان‌گیری زمان‌بندی‌شدهٔ داده‌های آینده هنوز وجود ندارد.

## نتیجهٔ بررسی نصب

- نسخهٔ بسته‌بندی‌شده با SQLite ماندگار اجرا شد؛ پس از توقف، راه‌انداز آن را از مسیر مستقل پروفایل ویندوز دوباره اجرا کرد. بعد از جابه‌جایی فایل اجرایی نیز نشست ورود مرورگر معتبر ماند.
- ورود حساب مالک فروشگاه بعد از راه‌اندازی دوباره موفق بود؛ برند، لوگو و شش شرط فاکتور دریافت شدند.
- صفحهٔ وب و API پاسخ ۲۰۰ دادند؛ بررسی سلامت SQLite مقدار `ok` داشت؛ دیتابیس دارای دو کاربر، یک فروشگاه و یک اشتراک محلی است.
- مدت دسترسی محلی در پنل ماژورا برای ۲۰ سال تنظیم شده است؛ داده‌ها با پایان نشست یا خاموش شدن رایانه حذف نمی‌شوند. تمدید یا ارتقای برنامه باید با حفظ این دیتابیس انجام شود.

**رمزها در سورس، این گزارش، Git یا فایل راه‌انداز ذخیره نشده‌اند.** آنها فقط هنگام تحویل مستقیم به مالک اعلام می‌شوند. فایل‌های دیتابیس، پشتیبان و لاگ در Git نادیده گرفته می‌شوند.

## محدودیت نگهداری

برای نسخهٔ بعدی، پیش از تعویض فایل‌های برنامه باید از دیتابیس با روش سازگار با SQLite/WAL پشتیبان گرفته و مسیر مهاجرت schema بررسی شود؛ `EnsureCreated` به‌تنهایی schema موجود را ارتقا نمی‌دهد. پاک کردن پروفایل ویندوز یا خرابی دیسک می‌تواند داده را از بین ببرد. برای بهره‌برداری تجاری، بازیابی آزمایشی، نسخهٔ پشتیبان دوره‌ای و آزمون SQL Server لازم است.
