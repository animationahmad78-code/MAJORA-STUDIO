# وضعیت واقعی وب MAJORA — مرجوعی، دریافت و مشاور

تاریخ: ۵ نوامبر ۲۰۲۶. این بسته **نسخهٔ نهایی قابل فروش نیست**. تغییرات این مرحله در همان مونوریپوی موجود ساخته شده‌اند و دادهٔ واقعی مشتری در آن وارد نشده است.

## انجام‌شده و آزموده

- مرجوعی جزئی یا کامل اقلام فاکتور با سقف تعداد باقی‌مانده، دلیل، ثبت تاریخچه و انتخاب بازگرداندن کالای سالم به انبار؛ محاسبهٔ خالص فروش و طلب مشتری از فروشگاه.
- بازپرداخت وجه فقط تا سقف طلب مشتری، با روش و شمارهٔ پیگیری؛ یادآور بازپرداخت و تغییر وضعیت فاکتور.
- شناسهٔ تکرارنشدنی برای مرجوعی، بازپرداخت، دریافت تکمیلی و صدور فاکتور؛ تکرار درخواستِ یکسان نباید دوبار ثبت شود.
- افزودن خودکار مشتری تازه هنگام صدور فاکتور؛ نمایش مانده و مرجوعی در فهرست فاکتورها، داشبورد، متن کپی و قالب چاپ.
- تنظیم سراسری API هوش مصنوعی سازگار با OpenAI Chat Completions در پنل مدیر MAJORA. کلید با ASP.NET Core Data Protection محافظت شده و در پاسخ خواندن تنظیمات ظاهر نمی‌شود. نشانی‌های محلی/خصوصی و redirect برای اتصال مسدود شده‌اند. بدون اتصال یا در حالت غیرفعال، پاسخ آماری داخلی فعال است.

## باقی‌مانده تا تحویل تجاری

1. حسابداری وب هنوز دفترکل دوبل، چک، تراز معتبر، مالیات و ماندهٔ آغاز دوره ندارد؛ برآورد ۳۰روزه جای حسابداری نهایی را نمی‌گیرد.
2. تطابق کامل با Android هنوز برقرار نیست: ویرایش و بایگانی فاکتور، افزایش قیمت گروهی، عکس کالا، PNG/PDF مستقل، انتقال دادهٔ Android، پیامک و اعلان عملیاتی در وب ناقص یا اجرا نشده‌اند.
3. API هوش مصنوعی فقط پروتکل سازگار با Chat Completions دارد؛ سرویس واقعی و هزینه/کیفیت پاسخ آزمون نشده‌اند. مشاور اقدام مالی خودکار نمی‌کند.
4. استقرار و مهاجرت روی SQL Server واقعی، آزمون چندکاربره/بار، امنیت مستقل، پشتیبان‌گیری و بازیابی واقعی و چاپ روی دستگاه مشتری انجام نشده است.

راهنمای استقرار در `web-deployment.md` و وضعیت هر نیاز در `REQUIREMENTS-TRACEABILITY.md` ثبت شده است. بستهٔ حاضر برای اتصال مستقیم به مشتریِ در انتظار با دادهٔ واقعی تأیید نشده است.
