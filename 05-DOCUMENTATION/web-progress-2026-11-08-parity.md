# وضعیت واقعی تطابق وب و Android — ۸ نوامبر ۲۰۲۶

این تغییرات روی شاخهٔ `feature/web-invoice-parity` همان مونوریپوی موجود انجام شد. **این بسته هنوز نسخهٔ نهایی قابل فروش یا برابر با APK نیست.** هیچ دادهٔ واقعی مشتری در آزمون‌ها استفاده نشد.

## قابلیت‌های اضافه‌شده در این مرحله

- فروش سه‌مرحله‌ای: انتخاب مشتری قبلی با جست‌وجو یا ثبت مشتری جدید، انتخاب کالا با جست‌وجو/دسته/صفحه‌بندی ۵۰تایی و سبد پایدار بین صفحه‌ها، بررسی پرداخت و ثبت. سرور قیمت و جمع دیده‌شده را پیش از صدور با قیمت فعلی مقایسه می‌کند و تغییر هم‌زمان را رد می‌کند.
- افزایش قیمت گروهی با انتخاب موردی یا همهٔ کالاهای فعال، درصد تا سه رقم اعشار، گرد کردن نیم‌ریال به بالا، تاریخچهٔ قابل جست‌وجوی قیمت قبل و بعد، شناسهٔ تکرارنشدنی و بازگردانی مشروط به تغییر نکردن قیمت‌ها پس از آن نوبت. قیمت فاکتورهای صادرشده ثابت می‌ماند.
- تصویر کالا در دیتابیس همان فروشگاه با دسترسی احراز هویت‌شده، محدودیت یک مگابایت و نوع JPEG/PNG/WebP. رابط وب انتخاب فایل و درخواست دوربین دارد. تجربهٔ واقعی دوربین موبایل آزمون نشده است.
- بایگانی و بازگردانی کالا، مشتری و فاکتور. فاکتور دارای ماندهٔ دریافت یا بازپرداخت باز قابل بایگانی نیست؛ پیش‌فاکتور قابل بایگانی است. سوابق مالی با بایگانی حذف نمی‌شوند.
- خروجی CSV مشتریان با BOM UTF-8، جداسازی فروشگاه‌ها و خنثی‌سازی مقدارهای آغازشونده با کاراکتر فرمول.

## کارهای باز برای ادعای «نسخهٔ نهایی»

1. تطابق سند فاکتور و قابلیت‌های Android هنوز کامل نیست: تخفیف انتخابی، ویرایش/نسخه‌بندی فاکتور صادرشده، خروجی مستقل PDF/PNG، چاپ فیزیکی، تاریخ شمسیِ ورودی یکپارچه، تنظیم دقیق تک‌تک فیلدها، راهنمای آموزشی و تنظیمات شخصی.
2. حسابداری وب دفترکل دوبل، ماندهٔ افتتاحیه، چک و سررسید آن، گزارش‌های قابل اتکا و تسویهٔ بانکی ندارد. برآورد فعلی سود جای گزارش مالی نهایی را نمی‌گیرد.
3. پیامک، اعلان عملیاتی، انتقال داده از APK، واردکردن Excel/CSV، حذف دائمی بایگانی با سیاست نگهداری مالی، پشتیبان‌گیری و بازیابی سرور و آزمون بازیابی هنوز اجرا نشده‌اند.
4. ارزیابی امنیت مستقل، آزمون فشار/هم‌زمانی روی SQL Server واقعی، آزمون مرورگرهای موبایل و استقرار روی هاست .NET/SQL Server واقعی انجام نشده است. هاست PHP قبلی طبق پاسخ پشتیبانی برای اجرای این API مناسب نیست.
5. سرویس AI واقعی و هزینه/کیفیت پاسخ آن آزمون نشده است. مشاور موجود اقدام مالی خودکار نمی‌کند.

تا بسته شدن این موارد و ثبت شواهد، شاخه و PR باید Draft بمانند و برای دادهٔ تجاری مشتری مستقر نشوند.
