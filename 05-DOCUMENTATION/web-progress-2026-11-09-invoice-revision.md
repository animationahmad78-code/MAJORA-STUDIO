# گزارش تکمیل اصلاح نسخه‌دار فاکتور وب — ۹ نوامبر ۲۰۲۶ UTC

این تغییر روی همان شاخهٔ `feature/web-invoice-parity` در مونوریپوی MAJORA-STUDIO انجام شد. **این نسخه هنوز محصول نهایی قابل فروش یا معادل کامل APK نیست.** دادهٔ آزمون در پایگاه جداگانهٔ محلی ساخته شد.

## تغییر اجراشده

- نسخهٔ ۱ فاکتورهای تازه در لحظهٔ صدور به‌صورت snapshot مستقل ذخیره می‌شود؛ پرداخت‌ها و تغییرات بعدی آن را بازنویسی نمی‌کنند. برای سندهای قدیمیِ پیش از این مهاجرت، نخستین اصلاح نسخهٔ موجود در آن لحظه را به عنوان مبنا ثبت می‌کند؛ بازسازی لحظهٔ صدور از دادهٔ موجود ممکن نیست.
- فرم «ویرایش فاکتور» در فهرست وب، اصلاح نام/تلفن مشتری، تاریخ شمسی، شرح/تعداد/فی/تخفیف ریالی ردیف‌ها، افزودن قلم دستی و جست‌وجو/افزودن کالا از فهرست را ارائه می‌کند. شمارهٔ فاکتور ثابت می‌ماند؛ نسخهٔ جدید و دلیل اصلاح در سابقه باقی می‌مانند. هر snapshot پیشین از همان قالب فاکتور برای نمایش و خروجی PDF/PNG/چاپ باز می‌شود؛ شمارهٔ نسخه در سند و نام فایل درج می‌شود.
- در تراکنش واحد، اختلاف تعداد اقلامِ کاتالوگی با موجودی تطبیق داده و حرکت انبار ثبت می‌شود. اصلاح با نسخهٔ قدیمی، موجودی ناکافی، مبلغ کمتر از وجه دریافت‌شده یا مرجوعی قبلی رد می‌شود. تغییر هویت مشتری، پیوند سوابق او را به مشتری سازگار منتقل می‌کند.
- API سابقهٔ نسخه‌ها فقط برای همان فروشگاه قابل خواندن است. مهاجرت SQL Server برای جدول نسخه‌ها و ستون `Revision` ساخته شد؛ دیتابیس توسعهٔ SQLite جدول‌ها را از مدل جدید می‌سازد.
- تبدیل پیش‌فاکتور به فروش نیز نسخهٔ تازه ثبت می‌کند تا متن پیش‌فاکتور قبلی و وضعیت فروش پس از تبدیل قابل تشخیص بمانند.

## بررسی واقعی

| بررسی | نتیجه |
|---|---|
| بیلد React/TypeScript وب و API .NET 10 | موفق، صفر خطای کامپایل؛ هشدار بستهٔ بزرگ JS وب باقی است |
| `npm test` و بیلد Android | ۳۴ آزمون موفق و بیلد موفق |
| اعتبارسنجی SQLite Android | ۱۷ جدول معتبر |
| آزمون یکپارچهٔ API روی دیتابیس مستقل | صدور و snapshot اولیه، اصلاح تعداد/تاریخ/مشتری، نگهداری نسخهٔ قبل، رد ویرایش قدیمی/کمبود موجودی/دریافت بیشتر/مرجوعی، جداسازی فروشگاه؛ موفق |
| مرورگر محلی | فاکتور آزمایشی ۲ قلم با جمع ۳٬۰۰۰٬۰۰۰ ریال به ۳ قلم و ۴٬۵۰۰٬۰۰۰ ریال اصلاح شد؛ مانده و نسخهٔ ۲ در فهرست و نسخهٔ ۱ در سابقه دیده شدند |
| جست‌وجو و خروجی نسخهٔ قبلی در مرورگر | جست‌وجوی «کمربند» کالای تازه را پیدا کرد، از تکرار کالای قبلی جلوگیری شد، و افزودن کمربند فاکتور را به نسخهٔ ۳ با جمع ۵٬۱۵۰٬۰۰۰ ریال رساند. نسخهٔ ۱ با ۲ قلم و جمع ۳٬۰۰۰٬۰۰۰ ریال و برچسب نسخه در متن سند در پیش‌نمایش قابل چاپ باز شد. خود فایل PDF/PNG نسخهٔ قبلی دانلود و بررسی نشده است |
| بستهٔ Windows منتشرشده | فایل اجرایی بالا آمد؛ سلامت API و صفحهٔ React پاسخ دادند |
